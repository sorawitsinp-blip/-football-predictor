# วิเคราะห์บอล — Matchday

เว็บแอปสำหรับดูคู่บอลประจำวัน และให้ AI (Claude) ช่วยวิเคราะห์/คาดผลคะแนน พร้อมเหตุผลประกอบ

⚠️ **ข้อควรทราบ**: ผลวิเคราะห์เป็นเพียงการประมวลผลจากข้อมูลสถิติและความน่าจะเป็น ไม่ใช่การการันตีผลการแข่งขัน โปรดใช้เป็นข้อมูลประกอบการตัดสินใจเท่านั้น

## โครงสร้างโปรเจกต์

```
football-predictor/
├── server.js          Express backend — เรียก football-data.org และ Anthropic API
├── package.json
├── .env.example       ตัวอย่างไฟล์ตั้งค่า (คัดลอกเป็น .env)
└── public/
    ├── index.html      หน้าเว็บหลัก (2 แท็บ: บอลเด็ดวันนี้ / วิเคราะห์เอง)
    ├── style.css        ธีมสีสนามหญ้า + ไฟสปอตไลท์
    └── app.js           ฟรอนต์เอนด์เรียก API และแสดงผล
```

## วิธีติดตั้งและรัน

### 1. ติดตั้ง Node.js
ต้องมี Node.js เวอร์ชัน 18 ขึ้นไป (มี `fetch` ในตัว) — ดาวน์โหลดที่ https://nodejs.org

### 2. สมัครขอ API key

- **ข้อมูลบอล (fixtures)**: สมัครฟรีที่ https://www.football-data.org/client/register (แผนฟรีรองรับลีกใหญ่ๆ เช่น พรีเมียร์ลีก, ลาลีกา, บุนเดสลีกา แต่มีข้อจำกัดจำนวนคำขอต่อนาที)
- **Claude API**: สร้างคีย์ที่ https://console.anthropic.com/settings/keys (การเรียกใช้ API มีค่าใช้จ่ายตามปริมาณการใช้งาน)
- **สถิติฟอร์มทีม (ไม่บังคับ แต่แนะนำ)**: AiScore API ผ่าน Parse — สมัครที่ https://parse.bot แล้วดูหน้า https://parse.bot/marketplace/07cbd6f0-9e9d-403d-9c6e-c092e6ffba7c/aiscore-com-api เพื่อรับ API key ฟรี (แผนฟรี 200 เครดิต/เดือน) ใช้ดึงค่าเฉลี่ยยิง/เสียต่อเกมจาก 5 นัดล่าสุดของแต่ละทีม มาเสริมให้ Claude วิเคราะห์แม่นขึ้น — ถ้าไม่ใส่คีย์นี้ ระบบยังทำงานได้ปกติ แค่ไม่มีสถิติส่วนนี้ประกอบ

### 3. ตั้งค่าไฟล์ .env

```bash
cd football-predictor
cp .env.example .env
```

แล้วเปิดไฟล์ `.env` ใส่คีย์ของคุณ:

```
FOOTBALL_DATA_API_KEY=คีย์ของคุณ
ANTHROPIC_API_KEY=คีย์ของคุณ
CLAUDE_MODEL=claude-sonnet-5
PARSE_API_KEY=คีย์ของคุณ (ไม่บังคับ)
AISCORE_BASE_URL=https://api.parse.bot/scraper/4159e902-84d5-4812-bcee-311effc7486d
PORT=3000
```

### 4. ติดตั้งแพ็กเกจและรันเซิร์ฟเวอร์

```bash
npm install
npm start
```

จากนั้นเปิดเบราว์เซอร์ไปที่ `http://localhost:3000`

## วิธีใช้งาน

- **แท็บ "บอลเด็ดวันนี้"**: เลือกวันที่ → กด "โหลดคู่บอล" ระบบจะดึงคู่บอลของวันนั้นจาก football-data.org ก่อน จากนั้น (ถ้าตั้งค่า `PARSE_API_KEY` ไว้) จะดึงรายการคู่บอลจาก AiScore มาจับคู่ทีมแบบ fuzzy match ตามชื่อทีม แล้วเรียกสถิติฟอร์ม 5 นัดล่าสุดมาเสริมในพรอมป์ก่อนส่งให้ Claude วิเคราะห์ทีละคู่ (ค่าเริ่มต้นวิเคราะห์สูงสุด 8 คู่ต่อครั้ง เพื่อไม่ให้ใช้โควตา API มากเกินไป — ปรับได้ที่พารามิเตอร์ `limit` ใน `/api/daily-picks?limit=10`) คู่ที่จับคู่กับ AiScore ได้จะมีป้าย "มีสถิติฟอร์ม AiScore" กำกับไว้ ผลจะเรียงจากคู่ที่ AI "มั่นใจ" มากไปน้อย คลิกที่คู่บอลเพื่อดูรายละเอียด
- **แท็บ "วิเคราะห์คู่บอลเอง"**: กรอกชื่อทีมเหย้า/ทีมเยือน และข้อมูลเพิ่มเติม (เช่น ผู้เล่นบาดเจ็บ ฟอร์มล่าสุด) แล้วให้ Claude วิเคราะห์ทันที โดยไม่ต้องพึ่งข้อมูลจาก API บอล — เหมาะกับคู่ที่ไม่มีในฐานข้อมูลฟรีของ football-data.org

## ข้อควรระวังเรื่อง AiScore matching

- ระบบจับคู่ทีมระหว่าง football-data.org กับ AiScore ด้วยการเทียบชื่อทีมแบบ token overlap (ดูฟังก์ชัน `findAiScoreMatch` ใน `server.js`) เพราะชื่อทีมจากสองแหล่งอาจสะกดไม่ตรงกันเป๊ะ (เช่น "Manchester United FC" vs "Manchester United") ถ้าจับคู่ไม่ได้ (คะแนนความเหมือน < 50%) ระบบจะข้ามสถิติ AiScore ไปเงียบๆ และใช้แค่ข้อมูลจาก football-data.org แทน
- แต่ละคู่ที่จับคู่ได้จะเสียเครดิต Parse เพิ่ม 1 เครดิตต่อคู่ (สำหรับ `get_match_team_form`) บวกกับ 2 เครดิตสำหรับดึง fixtures ของทั้งวัน (`get_scheduled_fixtures`) — ถ้าโหลด 8 คู่/วันและจับคู่ได้ทุกคู่ จะใช้ประมาณ 10 เครดิต/ครั้งที่กด "โหลดคู่บอล" ซึ่งแผนฟรี 200 เครดิต/เดือนใช้ได้ประมาณ 20 ครั้ง
- ถ้าไม่อยากพึ่งการจับคู่ชื่อทีมเลย ทางเลือกที่แม่นกว่าคือสลับไปใช้ AiScore `get_scheduled_fixtures` เป็นแหล่ง fixtures หลักแทน football-data.org ไปเลย (จะได้ `match_id`/`slug` ตรงกันอยู่แล้ว ไม่ต้องเดา) แต่ต้องแลกกับการไม่มีข้อมูลลีก/ฟอร์ม W-D-L ตัวอักษรแบบที่ football-data.org ให้มา

## ปรับแต่งเพิ่มเติมที่ทำได้

- **จำกัดเฉพาะบางลีก**: แก้ `fetchFixtures()` ใน `server.js` เพิ่มพารามิเตอร์ `competitions=PL,PD,BL1` ต่อท้าย URL (รหัสลีกดูได้จากเอกสาร football-data.org)
- **เพิ่มสถิติจริงในพรอมป์**: ตอนนี้ระบบส่งแค่ฟอร์มคร่าวๆ ให้ Claude หากต้องการความแม่นยำขึ้น ลองดึงสถิติเจอกันหรือผลย้อนหลัง (head-to-head) จาก API เพิ่ม แล้วใส่ในตัวแปร `extra` ก่อนส่งไป Claude
- **แคชผลวิเคราะห์**: ตอนนี้ทุกครั้งที่กด "โหลดคู่บอล" จะเรียก Claude API ใหม่ทุกคู่ ถ้าใช้งานบ่อยควรทำแคช (เช่น เก็บผลลง SQLite ต่อวันที่+คู่บอล) เพื่อประหยัดค่าใช้จ่าย
- **Deploy ขึ้นเซิร์ฟเวอร์จริง**: โปรเจกต์นี้เป็น Node app ธรรมดา สามารถ deploy ได้บน Render, Railway, Fly.io หรือ VPS ทั่วไป — อย่าลืมตั้งค่า environment variables (`FOOTBALL_DATA_API_KEY`, `ANTHROPIC_API_KEY`) บนแพลตฟอร์มปลายทางแทนการอัปโหลดไฟล์ `.env`
